# 净播 PureLive

> 只看画面，不问喧嚣。

净播是一款 Windows 桌面直播间播放器。把常看的直播间链接收进自己的「直播架」，播放时自动移走聊天、弹幕、礼物、排行榜、推荐位和活动横幅，只留下正在发生的画面。

## 下载

前往 [Releases](https://github.com/beibox1209/purelive/releases/latest) 下载：

- `PureLive-1.5.0-win64.zip`：解压后运行，启动最快，推荐。

## 功能

- **直播架**：添加任意网页直播间链接，支持备注名称、自动读取标题、收藏、搜索和最近观看。
- **拖拽添加**：从浏览器把直播间链接拖进窗口，确认后即可加入直播架。
- **纯净画面**：自动识别页面中的真实播放器，把视频移入独立的全屏舞台，并隐藏原网页。聊天、礼物按钮、弹幕和推荐不会出现在画面上。
- **状态识别**：主播未开播、直播已结束或站点要求登录验证时，会给出明确提示，而不是停在黑屏。
- **网页模式**：遇到需要登录、选择画质或站点提示时，一键切回完整网页，登录状态会在本地保留。
- **本地封面**：添加直播间后自动读取平台封面并保存到本机；观看时会再截取一张纯净画面作为封面，不上传。
- **播放控制**：暂停后会锁定画面，避免站点自动恢复播放；刷新按钮可重新接入直播。
- **清晰度调整**：哔哩哔哩、虎牙可在播放栏直接切换清晰度；斗鱼及其他站点会提示使用网页模式调整，需登录的高画质会给出说明。
- **单窗口播放**：点击直播间后直接在主窗口内切换到播放界面，不再另开播放窗口；点左上角返回即可回到直播架。
- **账号管理**：在「设置 → 账号管理」中查看各平台登录状态，应用内登录或退出，登录状态只保存在本机。
- **播放窗口**：播放 / 暂停、静音、清晰度、刷新、置顶、全屏；支持 `F11`、`空格`、`M` 快捷键。
- **实时画质增强（GPU）**：播放栏的「增强」按钮开启实时锐化/超分，几乎不增加延迟，适合低码率直播。
- **完全本地**：直播间链接、标题和截图保存在自己的电脑上，无需注册净播账号，也没有自建服务器。
- **减少打扰**：禁用 WebRTC/P2P 上传与本地监听，避免 Windows 防火墙弹窗，也减少后台流量。

## 使用

1. 双击 `PureLive.exe` 打开净播。
2. 点击「添加直播间」，粘贴直播间链接，例如：
   - `https://live.bilibili.com/545068`
   - `https://www.douyu.com/10739363`
   - `https://www.huya.com/660000`
   也可以直接从浏览器把直播间链接拖进窗口。
3. 添加后会尝试自动读取直播标题，也可以自己填写名称。
4. 点击卡片开始观看。播放界面会直接在当前窗口打开，默认使用「纯净」模式。
5. 播放栏的「画质」可切换清晰度；旁边的「增强」按钮可开启实时 GPU 画质增强。
6. 如果站点要求登录、调整画质或出现验证，点击播放栏里的「纯净」开关切换到「网页模式」，处理完再切回纯净模式。账号登录也可以从「设置 → 账号管理」进入对应平台的登录页。

### 账号管理

打开左下角「设置 → 账号管理」，可以查看哔哩哔哩、斗鱼、虎牙、抖音、Twitch、YouTube 的登录状态：

- 点「登录」会在当前窗口打开对应平台的登录页，完成登录后点左上角返回直播架。
- 点「退出」会清除该平台在净播内保存的 Cookie 和本地存储，不影响浏览器里的登录。
- 所有登录状态只保存在本机的 `persist:purelive` 会话中，不会上传。

### 画质增强

点播放栏的「增强」按钮，或在「画质」菜单里勾选「实时画质增强（GPU）」：

- 本地 WebGL 锐化/超分，适合低码率直播，几乎不增加延迟。
- 只处理画面，不会改变原视频的清晰度档位，也不会额外上传数据。

### 快捷键

| 场景 | 按键 |
| --- | --- |
| 添加直播间 | `Ctrl + N` |
| 搜索直播间 | `Ctrl + F` |
| 播放 / 暂停 | `空格` |
| 静音 / 取消静音 | `M` |
| 全屏 / 退出全屏 | `F11` |
| 退出全屏 | `Esc` |
| 关闭弹窗 / 菜单 | `Esc` |

## 常见问题

**画面一直显示「正在接通画面」？**

稍等几秒；如果主播未开播，软件会直接提示「主播暂未开播」。其他情况下可以点击「重新连接」，或切换到「网页模式」。部分站点会检测内嵌浏览器，或在直播结束后不提供视频元素。

**纯净模式里没有声音？**

播放窗口左上角的喇叭按钮可以取消静音。若站点本身把视频静音了，切换一次网页模式再切回纯净模式通常能恢复。

**如何登录？**

在播放窗口切换为「网页模式」，完成登录后再切回「纯净」。登录 Cookie 保存在本机的独立分区中，不会上传。

**清晰度切换失败？**

哔哩哔哩和虎牙会读取站点当前提供的清晰度列表。标有「登录」或切换时提示需要登录的画质，请先切到网页模式登录。斗鱼目前由播放器自动选择清晰度，可用网页模式手动调整。

**数据在哪里？**

点击左下角「设置」→「打开文件夹」。直播架数据为 `purelive-data.json`，缩略图位于 `thumbnails` 文件夹。

## 启动速度

- `PureLive-1.5.0-win64.zip` 解压一次后直接运行 `PureLive.exe`，启动最快，推荐日常使用。
- 发布页只提供 zip 版，不再分发启动较慢的单文件便携版。
- 程序会先显示直播架，再在后台补充封面，不会为了抓封面阻塞启动。

## 从源码运行

需要 Node.js 22+ 和 pnpm。

```powershell
pnpm install
pnpm start
```

打包 Windows 版本：

```powershell
pnpm run build
```

发布产物为 `dist/PureLive-1.5.0-win64.zip`。当前构建未做代码签名，Windows 首次运行时可能显示「未知发布者」提示，选择「更多信息 → 仍要运行」即可。

## 说明

- 本项目不下载、不转存直播流，只在本机浏览器组件中播放用户提供的网页。
- 「实时画质增强（GPU）」是本地 WebGL 锐化/超分着色器，不依赖云端或生成式模型。
- 请遵守直播平台的服务条款和内容版权；软件不提供绕过平台限制的能力。
- 站点页面结构随时可能变化，纯净模式的识别规则可能需要随更新维护。
